# Estudos

Anotações, exercícios, provas e projetos das matérias curso.

> **Template base:** este repositório foi criado a partir do [TemplateEstudos](https://github.com/pardallzxn-1327/TemplateEstudos), que define a estrutura padrão e o manual de organização da base de estudos.

## Disciplinas

| Disciplina | Conteúdo |
|---|---|
| [BancoDeDados](BancoDeDados/) | SQL, modelagem (MER/DER), normalização |
| [EstruturaDeDados](EstruturaDeDados/) | Complexidade, listas, árvores, grafos, hash |
| [FrontEnd](FrontEnd/) | HTML, CSS, JavaScript, frameworks |
| [POO](POO/) | Classes, herança, polimorfismo, SOLID |
| [SistemasOperacionais](SistemasOperacionais/) | Processos, escalonamento, memória, arquivos |

## Organização

Cada disciplina segue a mesma estrutura:

```
<Disciplina>/
├── Unidades/     # conteúdo por aula/tópico (anotações e resumo)
├── Exercicios/   # exercícios avulsos
├── Provas/       # anteriores/ e simulados/
├── Projetos/     # trabalhos da disciplina
└── Recursos/     # livros/, links/ e videos/
```
